# CSD 303 — Practice Problems

Interactive, self-grading quiz sets built from the **CSD 303: Speech Acoustics & Perception (Fall 2026)** lecture slides.

Each page is a single self-contained HTML file — open it in any browser, answer the
questions, hit **Check answer** to reveal the correct response with an explanation, then
**Submit quiz** for a score.

## Sets

| Page | Topic | Lecture |
|------|-------|---------|
| [`quiz-hearing.html`](quiz-hearing.html) | Hearing sounds & auditory scales (Bark, equal-loudness, cochlea) | 12 |
| [`quiz-phonemes.html`](quiz-phonemes.html) | Phoneme similarity & categorical perception (prototype magnet, Ganong) | 15 |
| [`quiz-illusions.html`](quiz-illusions.html) | Auditory illusions (phonemic restoration, Yanny/Laurel) | 16 |
| [`quiz-whistled.html`](quiz-whistled.html) | Whistled languages (f0- vs formant-based, where & why) | 17 |
| [`quiz-dsp.html`](quiz-dsp.html) | Intro to DSP (sampling, Nyquist, quantization, bits) | 22 |

Start from [`index.html`](index.html).

## Notes
- Questions and explanations are derived from the lecture slide content; treat them as
  study aids, not an answer key for graded work.
- No build step, no dependencies — pure HTML/CSS/JS.
